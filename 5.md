# Вопрос 5. Бинарные деревья поиска (BST). Основные операции (поиск, вставка, удаление, поворот). Оценка алгоритмической сложности. Сериализация и десериализация деревьев.

---

## 1. Определение и свойства

**Бинарное дерево поиска (Binary Search Tree, BST)** — это бинарное дерево, в котором для каждого узла $x$ выполняется **свойство упорядочения (BST property)**:
- Все ключи в **левом** поддереве узла $x$ **строго меньше** (или равны, если допускаются дубликаты) ключа узла $x$.
- Все ключи в **правом** поддереве узла $x$ **строго больше** ключа узла $x$.

Это свойство позволяет выполнять поиск, вставку и удаление аналогично бинарному поиску в отсортированном массиве, но в динамической структуре.

### Структура узла (C++)

Для всего вопроса будем использовать простую структуру узла:

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

struct Node {
    int key;
    Node* left;
    Node* right;
    
    Node(int k) : key(k), left(nullptr), right(nullptr) {}
};
```

## 2. Основные операции

### 2.1. Поиск (Search)

**Идея:** Начинаем с корня. Если искомый ключ равен ключу текущего узла — нашли. Если меньше — идём в левое поддерево. Если больше — в правое. Повторяем, пока не найдём или не упрёмся в `nullptr`.

**Алгоритм:**
1. Установить указатель `curr` на корень.
2. Пока `curr != nullptr`:
   - Если `key == curr->key`, вернуть `curr`.
   - Если `key < curr->key`, `curr = curr->left`.
   - Иначе `curr = curr->right`.
3. Если цикл завершился, ключа в дереве нет, вернуть `nullptr`.

**Код на C++ (итеративно и рекурсивно):**

```cpp
// Итеративный поиск (предпочтительнее, не тратит стек)
Node* search(Node* root, int key) {
    Node* curr = root;
    while (curr != nullptr) {
        if (key == curr->key) return curr;
        if (key < curr->key) 
            curr = curr->left;
        else 
            curr = curr->right;
    }
    return nullptr; // не найден
}

// Рекурсивный поиск
Node* searchRecursive(Node* root, int key) {
    if (root == nullptr || root->key == key) return root;
    if (key < root->key) return searchRecursive(root->left, key);
    return searchRecursive(root->right, key);
}
```

### 2.2. Вставка (Insert)

**Идея:** Вставка нового элемента всегда происходит в **лист** (или на место пустого поддерева). Мы спускаемся от корня так же, как при поиске, пока не найдём пустое место (`nullptr`), куда и помещаем новый узел.

**Алгоритм:**
1. Если дерево пусто, новый узел становится корнем.
2. Иначе идем от корня вниз:
   - Если `key < curr->key`, идем влево. Если левого потомка нет — вставляем туда.
   - Если `key > curr->key`, идем вправо. Если правого потомка нет — вставляем туда.
3. *(Опционально)* Если `key == curr->key`, игнорируем (или увеличиваем счётчик дубликатов).

**Код на C++:**

```cpp
// Возвращает указатель на корень (он мог измениться, если дерево было пустым)
Node* insert(Node* root, int key) {
    // База рекурсии: нашли пустое место
    if (root == nullptr) {
        return new Node(key);
    }

    if (key < root->key) {
        root->left = insert(root->left, key);
    } else if (key > root->key) {
        root->right = insert(root->right, key);
    }
    // если key == root->key, ничего не делаем (ключи уникальны)

    return root;
}
```

### 2.3. Удаление (Delete)

Удаление — самая сложная операция в BST. При удалении узла нужно сохранить свойство дерева поиска.
Рассматриваются **три случая**:

#### Случай 1: Узел — лист (нет потомков)
Просто удаляем его и возвращаем `nullptr` родителю.

#### Случай 2: Узел имеет ровно одного потомка
Заменяем удаляемый узел его единственным потомком (подтягиваем потомка на место родителя).

#### Случай 3: Узел имеет двух потомков
Мы не можем просто удалить его, так как «повиснут» два поддерева.
**Решение:** Находим **in-order преемника** (наименьший элемент в правом поддереве) или **in-order предшественника** (наибольший элемент в левом поддереве).
1. Копируем ключ преемника в удаляемый узел.
2. Рекурсивно удаляем узел-преемник из правого поддерева (он гарантированно будет иметь 0 или 1 потомка, то есть сведётся к случаю 1 или 2).

**Алгоритм поиска in-order преемника (минимум в правом поддереве):**
Идём в `node->right`, а затем всё время влево (`curr->left`), пока не упрёмся в `nullptr`.

**Код на C++:**

```cpp
// Вспомогательная функция: поиск минимума в поддереве
Node* findMin(Node* node) {
    while (node->left != nullptr) {
        node = node->left;
    }
    return node;
}

Node* remove(Node* root, int key) {
    if (root == nullptr) return nullptr;

    // 1. Поиск удаляемого узла
    if (key < root->key) {
        root->left = remove(root->left, key);
    } else if (key > root->key) {
        root->right = remove(root->right, key);
    } 
    // 2. Узел найден (key == root->key)
    else {
        // Случай 1 и 2: нет левого или нет правого потомка
        if (root->left == nullptr) {
            Node* temp = root->right;
            delete root;
            return temp;
        } else if (root->right == nullptr) {
            Node* temp = root->left;
            delete root;
            return temp;
        }

        // Случай 3: два потомка
        // Находим in-order преемника (минимум в правом поддереве)
        Node* successor = findMin(root->right);
        
        // Копируем ключ преемника в текущий узел
        root->key = successor->key;
        
        // Удаляем преемника из правого поддерева
        root->right = remove(root->right, successor->key);
    }
    return root;
}
```

### 2.4. Повороты (Rotations)

Повороты используются для изменения структуры дерева без нарушения свойства BST. Они являются основой для самобалансирующихся деревьев (AVL, Красно-чёрные, Декартовы — вопросы 6-9).

Существует два типа поворотов: **левый** и **правый**. Они симметричны.

#### Правый поворот (Right Rotate) вокруг узла `y`
Узел `y` опускается вниз, а его левый потомок `x` поднимается наверх. Правое поддерево `x` (назовём его $\beta$) становится левым поддеревом `y`.

```
      y                 x
     / \               / \
    x   C    --->     A   y
   / \                   / \
  A   B                 B   C
```
*Свойство BST сохраняется*, так как $A < x < B < y < C$.

#### Левый поворот (Left Rotate) вокруг узла `x`
Обратная операция. `x` опускается, `y` поднимается.

```
    x                   y
   / \                 / \
  A   y      --->     x   C
     / \             / \
    B   C           A   B
```

**Код на C++:**

```cpp
// Левый поворот вокруг узла x
// Возвращает новый корень этого поддерева (узел y)
Node* rotateLeft(Node* x) {
    if (x == nullptr || x->right == nullptr) return x;
    
    Node* y = x->right;
    Node* B = y->left;

    // Выполняем поворот
    y->left = x;
    x->right = B;

    // Теперь y — новый корень поддерева
    return y;
}

// Правый поворот вокруг узла y
// Возвращает новый корень этого поддерева (узел x)
Node* rotateRight(Node* y) {
    if (y == nullptr || y->left == nullptr) return y;
    
    Node* x = y->left;
    Node* B = x->right;

    // Выполняем поворот
    x->right = y;
    y->left = B;

    // Теперь x — новый корень поддерева
    return x;
}
```
> **Важно для экзамена:** Повороты выполняются за время $O(1)$, так как меняют указатели только у константного числа узлов (два узла и их поддеревья).

## 3. Оценка алгоритмической сложности

Пусть $n$ — количество узлов в дереве, $h$ — высота дерева.

| Операция | Время (через высоту) | Средний случай | Худший случай |
| :--- | :--- | :--- | :--- |
| **Поиск** | $O(h)$ | $O(\log n)$ | $O(n)$ |
| **Вставка** | $O(h)$ | $O(\log n)$ | $O(n)$ |
| **Удаление** | $O(h)$ | $O(\log n)$ | $O(n)$ |
| **Поворот** | $O(1)$ | $O(1)$ | $O(1)$ |

### Почему худший случай $O(n)$?
Если элементы вставляются в отсортированном порядке (например, 1, 2, 3, 4, 5), дерево вырождается в связный список (цепочку). Высота $h = n$, и все операции требуют прохода по всем элементам.

### Почему средний случай $O(\log n)$?
Если элементы вставляются в случайном порядке, математическое ожидание высоты случайного бинарного дерева поиска равно $O(\log n)$ (точнее $\approx 2.99 \log_2 n$ по теореме Рида/Девруа). 

> Именно проблема худшего случая $O(n)$ мотивирует использование **сбалансированных деревьев** (AVL, RB, Декартовы — вопросы 6-8), которые гарантируют $h = O(\log n)$ всегда.

## 4. Сериализация и десериализация деревьев

**Сериализация** — процесс преобразования структуры данных (дерева) в последовательность битов/байтов (например, строку или массив), чтобы сохранить её в файл или передать по сети.
**Десериализация** — обратный процесс восстановления точной копии дерева из этой последовательности.

### Проблема с обычными обходами
Если мы сохраним только In-order обход, мы получим отсортированный массив, из которого невозможно восстановить исходную структуру (любой BST с этими элементами даст тот же In-order).
Нужен **Pre-order** или **Post-order**, но обязательно с маркерами пустых узлов (nulls), иначе структура неоднозначна.

### Способ 1: Pre-order + маркеры NULL (самый популярный)

**Идея:** Записываем узлы в порядке "корень -> левый -> правый". Если встречаем `nullptr`, записываем специальный символ (например, `#` или `-1`).

**Сериализация (Pre-order):**
```cpp
void serialize(Node* root, std::vector<int>& out) {
    if (root == nullptr) {
        out.push_back(-1); // маркер пустого узла (предполагаем, что ключи >= 0)
        return;
    }
    out.push_back(root->key);
    serialize(root->left, out);
    serialize(root->right, out);
}
```

**Десериализация:**
Читаем массив слева направо. Первый элемент — корень. Затем рекурсивно читаем левое поддерево, затем правое.
```cpp
Node* deserializeHelper(const std::vector<int>& data, int& index) {
    if (index >= (int)data.size() || data[index] == -1) {
        index++;
        return nullptr;
    }
    
    Node* node = new Node(data[index]);
    index++;
    
    node->left = deserializeHelper(data, index);
    node->right = deserializeHelper(data, index);
    
    return node;
}

Node* deserialize(const std::vector<int>& data) {
    int index = 0;
    return deserializeHelper(data, index);
}
```
**Сложность:** $O(n)$ по времени и памяти для обоих процессов.

---

### Способ 2: Использование свойства BST (без маркеров NULL)

Поскольку мы знаем, что это BST, нам достаточно **только Pre-order** (или только Post-order) обхода без маркеров.

**Сериализация:** Просто делаем Pre-order обход и пишем ключи в массив.
```cpp
void serializeBST(Node* root, std::vector<int>& out) {
    if (root == nullptr) return;
    out.push_back(root->key);
    serializeBST(root->left, out);
    serializeBST(root->right, out);
}
```

**Десериализация:**
Первый элемент Pre-order — это корень. Все последующие элементы, которые **меньше** корня, принадлежат левому поддереву, а которые **больше** — правому.

```cpp
Node* deserializeBSTHelper(const std::vector<int>& data, int& index, int min_val, int max_val) {
    if (index >= (int)data.size()) return nullptr;

    int val = data[index];
    // Если значение не попадает в допустимый диапазон для этого поддерева,
    // значит оно принадлежит другой ветке
    if (val < min_val || val > max_val) return nullptr;

    // Значение подходит, создаем узел и переходим к следующему
    Node* node = new Node(val);
    index++;

    // Левое поддерево: значения должны быть в диапазоне [min_val, val]
    node->left = deserializeBSTHelper(data, index, min_val, val);
    // Правое поддерево: значения должны быть в диапазоне [val, max_val]
    node->right = deserializeBSTHelper(data, index, val, max_val);

    return node;
}

Node* deserializeBST(const std::vector<int>& data) {
    int index = 0;
    return deserializeBSTHelper(data, index, INT32_MIN, INT32_MAX);
}
```
**Сложность:** $O(n)$ по времени (каждый элемент обрабатывается один раз), $O(h)$ по памяти (стек рекурсии).

### Способ 3: Level-order (BFS)

Сериализация по уровням (в ширину) удобна тем, что визуально понятна. Пустые узлы также обозначаются маркерами.

**Сериализация (BFS):**
```cpp
std::vector<int> serializeLevelOrder(Node* root) {
    std::vector<int> out;
    if (root == nullptr) return out;

    std::queue<Node*> q;
    q.push(root);

    while (!q.empty()) {
        Node* curr = q.front();
        q.pop();

        if (curr == nullptr) {
            out.push_back(-1);
        } else {
            out.push_back(curr->key);
            q.push(curr->left);
            q.push(curr->right);
        }
    }
    return out;
}
```

**Десериализация (BFS):**
```cpp
Node* deserializeLevelOrder(const std::vector<int>& data) {
    if (data.empty() || data[0] == -1) return nullptr;

    Node* root = new Node(data[0]);
    std::queue<Node*> q;
    q.push(root);

    int i = 1;
    while (!q.empty() && i < (int)data.size()) {
        Node* curr = q.front();
        q.pop();

        // Левый потомок
        if (i < (int)data.size() && data[i] != -1) {
            curr->left = new Node(data[i]);
            q.push(curr->left);
        }
        i++;

        // Правый потомок
        if (i < (int)data.size() && data[i] != -1) {
            curr->right = new Node(data[i]);
            q.push(curr->right);
        }
        i++;
    }
    return root;
}
```

## 5. Резюме для экзамена

1. **BST** — дерево, где левое поддерево содержит меньшие ключи, правое — большие.
2. **Поиск, вставка, удаление** работают за $O(h)$. В среднем $h = O(\log n)$, в худшем (вырожденное дерево) $h = O(n)$.
3. **Удаление** имеет 3 случая: лист, один потомок, два потомка (замена на in-order преемника).
4. **Повороты (левый/правый)** меняют структуру локально за $O(1)$, сохраняя свойство BST. Нужны для балансировки.
5. **Сериализация** — перевод дерева в массив. Для однозначного восстановления общего дерева нужен обход с маркерами `NULL` (Pre-order/BFS). Для BST достаточно чистого Pre-order, восстанавливая через границы `(min, max)`. Десериализация работает за $O(n)$.
