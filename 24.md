# Вопрос 24. Построение суффиксного массива с помощью цифровой сортировки циклических строк

---

## 1. Идея алгоритма

Этот алгоритм (часто называемый **алгоритмом удвоения** или **doubling algorithm**) строит суффиксный массив за время $O(n \log n)$, используя идею **поразрядной сортировки (Radix Sort)**, применённой не к числам, а к **циклическим подстрокам** удваивающейся длины.

> **Ключевая идея:** На шаге $k$ мы имеем отсортированный порядок всех циклических подстрок длины $2^k$. Порядок подстрок длины $2^{k+1}$ можно получить за $O(n)$, рассматривая каждую подстроку длины $2^{k+1}$ как **пару** двух соседних подстрок длины $2^k$ и выполняя стабильную сортировку по этим парам. Поскольку пары состоят из целых чисел (классов эквивалентности), сортировка выполняется за линейное время через counting sort.

После $\lceil \log_2 n \rceil$ шагов длина подстрок $\geq n$, и порядок циклических подстрок совпадает с порядком обычных суффиксов (при наличии терминального символа `$`).

---

## 2. Алгоритм пошагово

### Шаг 0: Сортировка отдельных символов
Присваиваем каждому символу его **класс эквивалентности** (ранг) после сортировки. Одинаковые символы получают одинаковый класс.

### Шаг k → k+1: Удвоение длины
Каждая циклическая подстрока длины $2^{k+1}$, начинающаяся в позиции $i$, состоит из двух половин:
- Левая половина: подстрока длины $2^k$, начинающаяся в $i$ → класс $c[i]$
- Правая половина: подстрока длины $2^k$, начинающаяся в $(i + 2^k) \bmod n$ → класс $c[(i + 2^k) \bmod n]$

Таким образом, каждая подстрока длины $2^{k+1}$ однозначно определяется **парой** $(c[i], c[(i + 2^k) \bmod n])$.

Сортируем эти пары за $O(n)$ с помощью **стабильной сортировки подсчётом** (сначала по второму элементу, затем по первому). После сортировки пересчитываем классы эквивалентности для новых подстрок.

### Остановка
Когда длина $2^k \geq n$ или когда число различных классов равно $n$ (все подстроки уникальны).

## 3. Код на C++

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
#include <numeric>

std::vector<int> buildSuffixArray(const std::string& s) {
    int n = s.size();
    if (n == 0) return {};
    
    // === Шаг 0: сортировка отдельных символов ===
    std::vector<int> sa(n), cls(n);
    
    // Counting sort по символам
    const int ALPHA = 256;
    std::vector<int> cnt(ALPHA, 0);
    for (char c : s) cnt[(unsigned char)c]++;
    for (int i = 1; i < ALPHA; ++i) cnt[i] += cnt[i - 1];
    for (int i = n - 1; i >= 0; --i) {
        sa[--cnt[(unsigned char)s[i]]] = i;
    }
    
    // Присваиваем классы
    cls[sa[0]] = 0;
    int numClasses = 1;
    for (int i = 1; i < n; ++i) {
        if (s[sa[i]] != s[sa[i - 1]]) numClasses++;
        cls[sa[i]] = numClasses - 1;
    }
    
    // === Шаги удвоения ===
    for (int len = 1; len < n && numClasses < n; len *= 2) {
        // Каждая подстрока длины 2*len задаётся парой (cls[i], cls[(i+len)%n])
        // Сортируем пары radix sort'ом: сначала по второму элементу, потом по первому
        
        // Второй элемент пары для позиции i: cls[(i + len) % n]
        // Сортировка по второму элементу (counting sort)
        std::vector<int> newSa(n);
        std::vector<int> newCnt(std::max(numClasses, n), 0);
        
        for (int i = 0; i < n; ++i) {
            int secondClass = cls[(sa[i] + len) % n]; // нет, нужно сортировать индексы
            // Исправление: сортируем индексы 0..n-1 по парам
        }
        
        // Корректная реализация radix sort для пар:
        // 1) Сортируем по второму компоненту
        std::fill(newCnt.begin(), newCnt.end(), 0);
        for (int i = 0; i < n; ++i) {
            newCnt[cls[(i + len) % n]]++;
        }
        for (int i = 1; i < numClasses; ++i) newCnt[i] += newCnt[i - 1];
        
        std::vector<int> temp(n);
        for (int i = n - 1; i >= 0; --i) {
            int idx = (i + len) % n; // нет, сортируем по позиции начала
            // Перепишем корректно ниже
        }
        
        // === Корректная реализация ===
        // Сортировка по ВТОРОМУ элементу пары
        std::fill(newCnt.begin(), newCnt.end(), 0);
        for (int i = 0; i < n; ++i)
            newCnt[cls[(i + len) % n]]++;
        for (int i = 1; i < numClasses; ++i)
            newCnt[i] += newCnt[i - 1];
        for (int i = n - 1; i >= 0; --i) {
            int secondCls = cls[(i + len) % n];
            temp[--newCnt[secondCls]] = i;
        }
        
        // Сортировка по ПЕРВОМУ элементу пары (стабильная → результат отсортирован по паре)
        std::fill(newCnt.begin(), newCnt.end(), 0);
        for (int i = 0; i < n; ++i)
            newCnt[cls[temp[i]]]++;
        for (int i = 1; i < numClasses; ++i)
            newCnt[i] += newCnt[i - 1];
        for (int i = n - 1; i >= 0; --i) {
            int firstCls = cls[temp[i]];
            newSa[--newCnt[firstCls]] = temp[i];
        }
        
        sa = newSa;
        
        // Пересчёт классов эквивалентности
        std::vector<int> newCls(n);
        newCls[sa[0]] = 0;
        numClasses = 1;
        for (int i = 1; i < n; ++i) {
            int cur1 = cls[sa[i]], cur2 = cls[(sa[i] + len) % n];
            int prev1 = cls[sa[i-1]], prev2 = cls[(sa[i-1] + len) % n];
            if (cur1 != prev1 || cur2 != prev2)
                numClasses++;
            newCls[sa[i]] = numClasses - 1;
        }
        cls = newCls;
    }
    
    return sa;
}

int main() {
    std::string s = "banana$";
    auto sa = buildSuffixArray(s);
    
    std::cout << "SA for \"" << s << "\":\n";
    for (int i = 0; i < (int)sa.size(); ++i) {
        std::cout << "sa[" << i << "] = " << sa[i] 
                  << "  \"" << s.substr(sa[i]) << "\"\n";
    }
    return 0;
}
```

## 4. Доказательство корректности

**Индукция по $k$:** После $k$-го шага массив `cls` содержит корректные классы эквивалентности для всех циклических подстрок длины $2^k$, а массив `sa` содержит их лексикографический порядок.

-   **База ($k=0$):** Классы присвоены по отдельным символам после counting sort. Корректно.
-   **Переход:** Подстрока длины $2^{k+1}$ однозначно определяется парой классов двух половин длины $2^k$. Radix sort по этим парам даёт корректный лексикографический порядок подстрок длины $2^{k+1}$. Пересчёт классов сохраняет инвариант.

Когда $2^k \geq n$, циклическая подстрока длины $2^k$ полностью определяет обычный суффикс (благодаря терминальному символу `$`, который меньше любого другого символа, «хвост» за пределами строки не влияет на порядок). Следовательно, порядок циклических подстрок совпадает с порядком суффиксов. $\blacksquare$

## 5. Оценка сложности

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Число итераций** | $\lceil \log_2 n \rceil$ | Длина удваивается каждый шаг |
| **Время одной итерации** | $O(n)$ | Два прохода counting sort + пересчёт классов |
| **Общее время** | $O(n \log n)$ | $O(n) \times O(\log n)$ |
| **Память** | $O(n)$ | Массивы sa, cls, temp, cnt |

> Существуют алгоритмы построения SA за $O(n)$ (SA-IS, DC3/Kärkkäinen-Sanders), но алгоритм удвоения является наиболее простым для понимания и реализации, и именно он подразумевается в формулировке вопроса («цифровая сортировка циклических строк»).

## 7. Резюме для экзамена

1. **Идея:** Представляем суффиксы как циклические подстроки. На каждом шаге удваиваем длину, сортируя пары классов эквивалентности за $O(n)$ через radix/counting sort.
2. **Циклические строки:** Позволяют единообразно обрабатывать «хвосты» без специальных случаев. Терминальный `$` гарантирует совпадение порядка циклических и обычных суффиксов при достаточной длине.
3. **Radix sort для пар:** Сначала стабильная сортировка по второму элементу пары, затем по первому. Оба прохода — counting sort за $O(n)$.
4. **Сложность:** $O(n \log n)$ времени, $O(n)$ памяти.
5. **Корректность:** Доказывается индукцией по длине подстрок. При $2^k \geq n$ порядок циклических подстрок = порядок суффиксов.

> **На экзамене обязательно:** Показать код или псевдокод radix sort для пар, объяснить зачем нужны циклические строки и терминальный символ, и оценить сложность $O(n \log n)$.
