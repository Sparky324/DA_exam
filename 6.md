# Вопрос 6. AVL-деревья. Основные операции. Теорема о высоте AVL-дерева (с доказательством)

---

## 1. Определение и свойства

**AVL-дерево** — это бинарное дерево поиска (BST, вопрос 5), в котором для **каждого** узла выполняется условие баланса:

> Разность высот левого и правого поддеревьев (называемая **balance factor**, BF) не превышает 1 по модулю.

$$BF(x) = height(x.left) - height(x.right) \in \{-1, 0, 1\}$$

Это гарантирует, что высота дерева всегда $O(\log n)$, а значит поиск, вставка и удаление работают за $O(\log n)$ даже в худшем случае (в отличие от обычного BST).

### Структура узла

Для AVL-дерева удобно хранить высоту в каждом узле, чтобы быстро вычислять баланс-фактор.

```cpp
#include <iostream>
#include <algorithm>

struct Node {
    int key;
    int height; // высота поддерева с корнем в этом узле
    Node* left;
    Node* right;

    Node(int k) : key(k), height(1), left(nullptr), right(nullptr) {}
};
```

### Вспомогательные функции

```cpp
// Получить высоту (безопасно для nullptr)
int getHeight(Node* node) {
    return node ? node->height : 0;
}

// Вычислить баланс-фактор
int getBalance(Node* node) {
    return node ? getHeight(node->left) - getHeight(node->right) : 0;
}

// Обновить высоту узла на основе потомков
void updateHeight(Node* node) {
    if (node) {
        node->height = 1 + std::max(getHeight(node->left), getHeight(node->right));
    }
}
```

## 2. Основные операции

Все операции основаны на **поворотах** (из вопроса 5). В AVL-дереве используется 4 типа поворотов для восстановления баланса после вставки или удаления.

### 2.1. Повороты (Rotations)

Повороты локально меняют структуру, сохраняя свойство BST, и уменьшают высоту разбалансированного поддерева.

#### Малый левый поворот (Left Rotation, LL)
Применяется, когда дисбаланс вправо ($BF = -2$), и правый потомок тоже «смотрит» вправо ($BF \leq 0$).

```
    x (BF=-2)             y
     \                   / \
      y       --->      x   C
       \
        C
```

```cpp
Node* rotateLeft(Node* x) {
    Node* y = x->right;
    Node* B = y->left;

    // Поворот
    y->left = x;
    x->right = B;

    // ОБЯЗАТЕЛЬНО: обновляем высоты снизу вверх!
    updateHeight(x);
    updateHeight(y);

    return y; // y — новый корень поддерева
}
```

#### Малый правый поворот (Right Rotation, RR)
Зеркальная ситуация: дисбаланс влево ($BF = 2$), левый потомок «смотрит» влево ($BF \geq 0$).

```
        y (BF=2)          x
       /                 / \
      x       --->      A   y
     /                       \
    A                         B
```

```cpp
Node* rotateRight(Node* y) {
    Node* x = y->left;
    Node* B = x->right;

    // Поворот
    x->right = y;
    y->left = B;

    updateHeight(y);
    updateHeight(x);

    return x;
}
```

#### Большой левый поворот (Left-Right, LR)
Дисбаланс вправо ($BF = -2$), но правый потомок «смотрит» влево ($BF > 0$).
Сначала делаем **правый** поворот вокруг правого потомка, затем **левый** вокруг корня.

```
    x                  x                  z
     \                  \                / \
      y (BF>0)  --->     z      --->     x   y
     /                    \
    z                      y
```

#### Большой правый поворот (Right-Left, RL)
Дисбаланс влево ($BF = 2$), левый потомок «смотрит» вправо ($BF < 0$).
Сначала **левый** поворот вокруг левого потомка, затем **правый** вокруг корня.

### 2.2. Балансировка узла

Общая функция, которая вызывается после каждой вставки/удаления при возврате из рекурсии:

```cpp
Node* balance(Node* node) {
    if (!node) return nullptr;
    
    updateHeight(node);
    int bf = getBalance(node);

    // Левый перевес (BF = 2)
    if (bf == 2) {
        // Если левый потомок смотрит вправо -> сначала малый левый поворот
        if (getBalance(node->left) < 0) {
            node->left = rotateLeft(node->left);
        }
        return rotateRight(node);
    }

    // Правый перевес (BF = -2)
    if (bf == -2) {
        // Если правый потомок смотрит влево -> сначала малый правый поворот
        if (getBalance(node->right) > 0) {
            node->right = rotateRight(node->right);
        }
        return rotateLeft(node);
    }

    return node; // баланс не нарушен
}
```

### 2.3. Поиск (Search)

Поиск в AVL-дереве **абсолютно идентичен** поиску в обычном BST (вопрос 5). Никакой дополнительной логики не нужно, так как свойство BST сохраняется.

```cpp
Node* search(Node* root, int key) {
    if (root == nullptr || root->key == key) return root;
    if (key < root->key) return search(root->left, key);
    return search(root->right, key);
}
```
**Сложность:** $O(h) = O(\log n)$.

---

### 2.4. Вставка (Insert)

**Алгоритм:**
1. Выполняем стандартную рекурсивную вставку как в BST.
2. При возврате из рекурсии (поднимаясь вверх к корню) обновляем высоту текущего узла.
3. Проверяем баланс-фактор. Если он стал $\pm 2$, выполняем нужный тип поворота.
4. Возвращаем новый корень поддерева.

> **Важно:** После одной вставки достаточно **не более одного поворота** (одинарного или двойного) в самом нижнем разбалансированном узле, чтобы всё дерево снова стало AVL.

```cpp
Node* insert(Node* root, int key) {
    // 1. Стандартная вставка в BST
    if (root == nullptr) return new Node(key);

    if (key < root->key)
        root->left = insert(root->left, key);
    else if (key > root->key)
        root->right = insert(root->right, key);
    else
        return root; // дубликаты не вставляем

    // 2. Обновляем высоту предка
    updateHeight(root);

    // 3. Балансируем и возвращаем новый корень
    return balance(root);
}
```
**Сложность:** Спуск вниз $O(\log n)$ + подъём вверх $O(\log n)$ + один поворот $O(1)$. Итого $O(\log n)$.

### 2.5. Удаление (Delete)

Удаление сложнее вставки, так как может потребовать **несколько поворотов** на пути к корню (до $O(\log n)$ поворотов).

**Алгоритм:**
1. Ищем узел как в BST.
2. Три случая (как в вопросе 5):
   - Лист: удаляем.
   - Один потомок: заменяем на потомка.
   - Два потомка: находим in-order преемника (минимум в правом поддереве), копируем его ключ, рекурсивно удаляем преемника.
3. При возврате из рекурсии обновляем высоту и балансируем **каждый** узел на пути к корню.

```cpp
// Поиск минимума
Node* findMin(Node* node) {
    while (node->left) node = node->left;
    return node;
}

Node* remove(Node* root, int key) {
    if (!root) return nullptr;

    // 1. Поиск
    if (key < root->key)
        root->left = remove(root->left, key);
    else if (key > root->key)
        root->right = remove(root->right, key);
    else {
        // 2. Узел найден
        if (!root->left || !root->right) {
            Node* temp = root->left ? root->left : root->right;
            delete root;
            return temp; // может быть nullptr
        } else {
            // Два потомка
            Node* successor = findMin(root->right);
            root->key = successor->key;
            root->right = remove(root->right, successor->key);
        }
    }

    // 3. Балансировка на обратном пути
    return balance(root);
}
```
**Сложность:** $O(\log n)$.

## 3. Теорема о высоте AVL-дерева (с доказательством)

Это ключевой теоретический вопрос. Нужно доказать, что AVL-дерево действительно сбалансировано.

### Формулировка

> **Теорема.** Высота $h$ AVL-дерева, содержащего $n$ узлов, удовлетворяет неравенству:
> $$h \leq C \cdot \log_2(n + 2)$$
> где $C \approx 1.44$. То есть $h = O(\log n)$.

Более точная формулировка через минимум узлов: пусть $N(h)$ — **минимальное** количество узлов в AVL-дереве высоты $h$. Тогда:
$$N(h) \geq F_{h+2} - 1$$
где $F_k$ — $k$-е число Фибоначчи.

### Доказательство

**Шаг 1. Рекуррентное соотношение для $N(h)$**

Чтобы построить AVL-дерево высоты $h$ с **минимальным** числом узлов, мы должны сделать его максимально «разреженным».
Корень имеет высоту $h$. Чтобы минимизировать общее число узлов, одно из поддеревьев должно иметь высоту $h-1$, а другое — максимально допустимую по условию AVL, то есть $h-2$ (так как разница высот не больше 1).

Тогда:
$$N(h) = 1 + N(h-1) + N(h-2)$$
Базовые случаи:
- $N(0) = 1$ (один узел — лист, высота 1 в нашей нотации, но если считать высоту пустого дерева 0, а листа 1, то $N(1)=1, N(2)=2$).
Давайте используем стандартную нотацию: высота пустого дерева $= 0$, высота листа $= 1$.
- $N(0) = 0$
- $N(1) = 1$
- $N(2) = 2$ (корень + 1 потомок)

Проверим: $N(3) = 1 + N(2) + N(1) = 1 + 2 + 1 = 4$.
$N(4) = 1 + 4 + 2 = 7$.

**Шаг 2. Связь с числами Фибоначчи**

Числа Фибоначчи определяются как:
$$F_0 = 0, \quad F_1 = 1, \quad F_k = F_{k-1} + F_{k-2}$$
Последовательность: 0, 1, 1, 2, 3, 5, 8, 13, 21...

Заметим, что наша рекурренция $N(h) = N(h-1) + N(h-2) + 1$ очень похожа на Фибоначчи.
Докажем по индукции, что:
$$N(h) = F_{h+2} - 1$$

*База:*
- $h = 0$: $N(0) = 0$. $F_2 - 1 = 1 - 1 = 0$. ✅
- $h = 1$: $N(1) = 1$. $F_3 - 1 = 2 - 1 = 1$. ✅

*Переход:* Пусть верно для всех $k < h$.
$$N(h) = 1 + N(h-1) + N(h-2)$$
$$= 1 + (F_{h+1} - 1) + (F_h - 1)$$
$$= F_{h+1} + F_h - 1$$
$$= F_{h+2} - 1$$
Что и требовалось доказать. $\blacksquare$ (для связи с Фибоначчи).

**Шаг 3. Оценка высоты через $n$**

Известно, что числа Фибоначчи растут экспоненциально:
$$F_k \approx \frac{\varphi^k}{\sqrt{5}}$$
где $\varphi = \frac{1 + \sqrt{5}}{2} \approx 1.618$ — золотое сечение.

Так как $n \geq N(h) = F_{h+2} - 1$, то:
$$n + 1 \geq F_{h+2} \approx \frac{\varphi^{h+2}}{\sqrt{5}}$$

Логарифмируем:
$$\log_\varphi(n + 1) \geq h + 2 - \log_\varphi(\sqrt{5})$$
$$h \leq \log_\varphi(n + 1) + C'$$

Перейдём к двоичному логарифму:
$$\log_\varphi(x) = \frac{\log_2(x)}{\log_2(\varphi)} \approx \frac{\log_2(x)}{0.694} \approx 1.44 \cdot \log_2(x)$$

Следовательно:
$$h \leq 1.44 \cdot \log_2(n + 1) + const = O(\log n)$$

**Вывод:** Высота AVL-дерева из $n$ узлов никогда не превышает $\approx 1.44 \log_2 n$. Это строго доказывает, что все основные операции работают за $O(\log n)$. $\blacksquare$

## 4. Полный пример использования (C++)

```cpp
void printTree(Node* root, int space = 0) {
    if (!root) return;
    space += 5;
    printTree(root->right, space);
    std::cout << "\n";
    for (int i = 5; i < space; i++) std::cout << " ";
    std::cout << root->key << "(h=" << root->height << ",bf=" << getBalance(root) << ")\n";
    printTree(root->left, space);
}

int main() {
    Node* root = nullptr;
    
    // Вставка, которая вызовет все типы поворотов
    int keys[] = {10, 20, 30, 40, 50, 25};
    for (int k : keys) {
        root = insert(root, k);
    }

    std::cout << "AVL-дерево после вставок:\n";
    printTree(root);

    // Удаление
    root = remove(root, 40);
    std::cout << "\nПосле удаления 40:\n";
    printTree(root);

    return 0;
}
```

## 5. Сводная таблица сложности

| Операция | Худший случай | Средний случай | Примечание |
| :--- | :--- | :--- | :--- |
| **Поиск** | $O(\log n)$ | $O(\log n)$ | Как в BST |
| **Вставка** | $O(\log n)$ | $O(\log n)$ | Максимум 1-2 поворота |
| **Удаление** | $O(\log n)$ | $O(\log n)$ | До $O(\log n)$ поворотов |
| **Память** | $O(n)$ | $O(n)$ | +1 поле `height` в узле |

## 6. Резюме для экзамена

1. **AVL-дерево** — BST с условием $|h_L - h_R| \leq 1$ для каждого узла.
2. **Операции:** Поиск как в BST. Вставка/удаление — стандартный спуск + подъём с обновлением высот и **балансировкой** (4 типа поворотов: LL, RR, LR, RL).
3. **Вставка** требует $\leq 2$ поворотов. **Удаление** может потребовать $O(\log n)$ поворотов.
4. **Теорема о высоте:** Минимальное число узлов $N(h) = F_{h+2} - 1$ (числа Фибоначчи). Отсюда $h \leq 1.44 \log_2 n$, что доказывает гарантированную логарифмическую сложность всех операций.
