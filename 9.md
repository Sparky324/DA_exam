# Вопрос 9. Неявные декартовы деревья (Implicit Treap). Основные операции

---

## 1. Идея и отличие от обычного Treap

В обычном декартовом дереве (вопрос 8) каждый узел хранит явный ключ $x$ (например, число), по которому выполняется свойство BST.

В **неявном декартовом дереве (Implicit Treap)** у узлов **нет явного ключа**. Вместо этого роль ключа играет **позиция элемента в массиве** (индекс). Позиция определяется динамически через размер левого поддерева.

> **Зачем это нужно?** Implicit Treap позволяет работать с последовательностью элементов как с динамическим массивом, поддерживая следующие операции за $O(\log n)$:
> - Вставка элемента по индексу
> - Удаление элемента по индексу
> - Обращение к элементу по индексу
> - Разворот (reverse) произвольного отрезка
> - Циклический сдвиг
> - Сумма/минимум/максимум на отрезке (с ленивым распространением)

По сути, это **динамический массив с логарифмическими операциями модификации**, чего не может дать ни `std::vector`, ни обычный Treap.

### Структура узла

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
#include <utility>
#include <algorithm>

struct Node {
    int val;        // Значение элемента (НЕ ключ!)
    int priority;   // Приоритет для кучи
    int size;       // Размер поддерева (ключевое поле!)
    bool rev;       // Ленивый флаг разворота
    
    Node* left;
    Node* right;

    Node(int v) : val(v), priority(rand()), size(1), rev(false), 
                  left(nullptr), right(nullptr) {}
};

using pnode = Node*;
```

## 2. Поддержание размера поддерева

Поскольку позиция элемента определяется размером левого поддерева, мы обязаны поддерживать поле `size` актуальным после каждой модификации.

```cpp
// Получить размер (безопасно для nullptr)
int getSize(pnode t) {
    return t ? t->size : 0;
}

// Пересчитать размер узла на основе потомков
void updateSize(pnode t) {
    if (t) {
        t->size = 1 + getSize(t->left) + getSize(t->right);
    }
}
```

> **Важно:** `updateSize` нужно вызывать в конце каждого `merge`, `split`, и после любых структурных изменений.

---

## 3. Ленивое распространение (Lazy Propagation)

Для операций вроде разворота отрезка мы не можем физически развернуть всё поддерево сразу — это $O(n)$. Вместо этого ставим флаг `rev` на корень нужного поддерева и **проталкиваем (push)** его вниз только когда спускаемся в это поддерево.

```cpp
void push(pnode t) {
    if (t && t->rev) {
        // Физически меняем местами детей
        std::swap(t->left, t->right);
        
        // Проталкиваем флаг в детей
        if (t->left)  t->left->rev ^= true;
        if (t->right) t->right->rev ^= true;
        
        // Сбрасываем флаг у текущего узла
        t->rev = false;
    }
}
```

> **Критически важно:** `push` нужно вызывать **в начале** `split` и `merge` перед любым обращением к детям!

## 4. Операция Split (по позиции)

В неявном дереве `split` делит дерево не по значению ключа, а по **позиции (индексу)**.

**Задача:** Разделить дерево $T$ так, чтобы в левом дереве $L$ оказалось ровно `pos` первых элементов, а в правом $R$ — все остальные.

**Алгоритм:**
1. Делаем `push` (обязательно!).
2. Вычисляем позицию текущего корня: `curPos = getSize(t->left)`.
3. Если `curPos >= pos`: нужный разрез находится в левом поддереве. Рекурсивно делим левое поддерево. Правая часть результата цепляется как новый левый потомок корня.
4. Если `curPos < pos`: корень и левое поддерево уходят в $L$. Нужно ещё `pos - curPos - 1` элементов из правого поддерева. Рекурсивно делим правое.

```cpp
// Делим T на L (первые pos элементов) и R (остальные)
void split(pnode t, int pos, pnode& L, pnode& R) {
    if (!t) {
        L = R = nullptr;
        return;
    }
    
    push(t); // ОБЯЗАТЕЛЬНО перед доступом к детям!
    
    int curPos = getSize(t->left); // 0-индексированная позиция корня
    
    if (curPos >= pos) {
        // Корень уходит в R, делим левое поддерево
        split(t->left, pos, L, t->left);
        R = t;
    } else {
        // Корень уходит в L, делим правое поддерево
        // Из правого поддерева берём (pos - curPos - 1) элементов
        split(t->right, pos - curPos - 1, t->right, R);
        L = t;
    }
    
    updateSize(t); // ОБЯЗАТЕЛЬНО после изменения структуры!
}
```

## 5. Операция Merge

Merge в неявном дереве **идентичен** merge в обычном Treap (вопрос 8), но с добавлением `push` и `updateSize`. Условие «все ключи L меньше ключей R» здесь выполнено автоматически, потому что $L$ содержит первые элементы последовательности, а $R$ — последние.

```cpp
pnode merge(pnode L, pnode R) {
    if (!L) return R;
    if (!R) return L;
    
    push(L); // ОБЯЗАТЕЛЬНО!
    push(R);
    
    if (L->priority > R->priority) {
        L->right = merge(L->right, R);
        updateSize(L);
        return L;
    } else {
        R->left = merge(L, R->left);
        updateSize(R);
        return R;
    }
}
```

## 6. Основные операции над последовательностью

Все операции строятся на комбинации `split` и `merge`.

### 6.1. Вставка элемента `val` по индексу `pos`

```cpp
pnode insertAt(pnode root, int pos, int val) {
    pnode L, R;
    split(root, pos, L, R);          // Первые pos элементов | остальные
    
    pnode newNode = new Node(val);
    pnode temp = merge(L, newNode);  // Добавляем новый элемент в конец L
    root = merge(temp, R);           // Приклеиваем R обратно
    
    return root;
}
```

### 6.2. Удаление элемента по индексу `pos`

```cpp
pnode removeAt(pnode root, int pos) {
    pnode L, mid, R;
    split(root, pos, L, mid);        // [0..pos-1] | [pos..end]
    split(mid, 1, mid, R);           // [pos] | [pos+1..end]
    
    delete mid;                       // Удаляем элемент
    root = merge(L, R);              // Склеиваем оставшиеся части
    
    return root;
}
```

### 6.3. Разворот отрезка [l, r]

Это классическая задача, демонстрирующая мощь implicit treap.

```cpp
pnode reverseRange(pnode root, int l, int r) {
    pnode L, mid, R;
    
    // Вырезаем отрезок [l, r]
    split(root, l, L, mid);          // [0..l-1] | [l..end]
    split(mid, r - l + 1, mid, R);   // [l..r] | [r+1..end]
    
    // Ставим ленивый флаг разворота
    if (mid) mid->rev ^= true;
    
    // Склеиваем обратно
    root = merge(L, mid);
    root = merge(root, R);
    
    return root;
}
```

### 6.4. Доступ к элементу по индексу

Можно реализовать через рекурсивный спуск (без split/merge):

```cpp
int getByIndex(pnode t, int pos) {
    push(t); // Обязательно!
    
    int leftSize = getSize(t->left);
    if (pos == leftSize) return t->val;
    if (pos < leftSize) return getByIndex(t->left, pos);
    return getByIndex(t->right, pos - leftSize - 1);
}
```

### 6.5. Вывод последовательности (In-order обход)

```cpp
void printSequence(pnode t) {
    if (!t) return;
    push(t); // Обязательно для корректного порядка!
    printSequence(t->left);
    std::cout << t->val << " ";
    printSequence(t->right);
}
```

## 7. Оценка сложности

| Операция | Средняя сложность | Худший случай | Примечание |
| :--- | :--- | :--- | :--- |
| **Split** | $O(\log n)$ | $O(n)$ | Спуск по высоте дерева |
| **Merge** | $O(\log n)$ | $O(n)$ | Спуск по высоте дерева |
| **Вставка по индексу** | $O(\log n)$ | $O(n)$ | 2 × split/merge |
| **Удаление по индексу** | $O(\log n)$ | $O(n)$ | 2 × split/merge |
| **Разворот отрезка** | $O(\log n)$ | $O(n)$ | 2 × split/merge + O(1) флаг |
| **Доступ по индексу** | $O(\log n)$ | $O(n)$ | Прямой спуск |
| **Память** | $O(n)$ | $O(n)$ | Поля size, rev в каждом узле |

Как и для обычного Treap, ожидаемая высота при случайных приоритетах составляет $O(\log n)$, поэтому все операции работают за логарифм в среднем.

## 8. Полный пример использования

```cpp
int main() {
    srand(time(0));
    pnode root = nullptr;

    // Строим последовательность [1, 2, 3, 4, 5]
    for (int i = 1; i <= 5; ++i) {
        root = insertAt(root, i - 1, i);
    }

    std::cout << "Исходная: ";
    printSequence(root); // 1 2 3 4 5
    std::cout << "\n";

    // Разворачиваем отрезок [1, 3] (элементы 2, 3, 4)
    root = reverseRange(root, 1, 3);
    std::cout << "После reverse(1,3): ";
    printSequence(root); // 1 4 3 2 5
    std::cout << "\n";

    // Вставляем 99 по индексу 2
    root = insertAt(root, 2, 99);
    std::cout << "После insert(2, 99): ";
    printSequence(root); // 1 4 99 3 2 5
    std::cout << "\n";

    // Элемент по индексу 3
    std::cout << "Элемент [3]: " << getByIndex(root, 3) << "\n"; // 3

    // Удаляем элемент по индексу 0
    root = removeAt(root, 0);
    std::cout << "После remove(0): ";
    printSequence(root); // 4 99 3 2 5
    std::cout << "\n";

    return 0;
}
```

### Вывод:
```
Исходная: 1 2 3 4 5 
После reverse(1,3): 1 4 3 2 5 
После insert(2, 99): 1 4 99 3 2 5 
Элемент [3]: 3
После remove(0): 4 99 3 2 5 
```

## 9. Расширения (для полноты ответа)

Implicit Treap легко расширяется для поддержки дополнительных операций на отрезках:

- **Сумма на отрезке:** Храним в узле поле `sum`. Обновляем в `updateSize` (переименованной в `update`). При `push` для операции присвоения на отрезке проталкиваем значение.
- **Минимум/максимум на отрезке:** Аналогично сумме, храним `min`/`max`.
- **Присвоение значения на отрезке:** Ленивый флаг `assign`. В `push` устанавливаем `val` и сбрасываем флаг у детей.
- **Циклический сдвиг на k позиций:** Два вызова `split` + два вызова `merge`.

## 10. Резюме для экзамена

1. **Неявное декартово дерево** — Treap без явного ключа. Позиция элемента определяется размером левого поддерева (`size`).
2. **Ключевые отличия от обычного Treap:** поля `size` и `rev` (lazy flag), обязательные вызовы `updateSize` и `push`.
3. **Split по позиции:** Делит дерево так, чтобы слева оказалось ровно `pos` элементов. Использует `getSize(left)` вместо сравнения ключей.
4. **Merge:** Идентичен обычному, но с `push` и `updateSize`.
5. **Операции:** Вставка/удаление по индексу, разворот отрезка, доступ по индексу — всё через комбинацию `split`/`merge` за $O(\log n)$.
6. **Ленивое распространение:** Флаг `rev` ставится на корень поддерева и проталкивается вниз только при необходимости, что делает разворот отрезка $O(\log n)$ вместо $O(n)$.
