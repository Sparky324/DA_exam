# Вопрос 17. Алгоритм Бойера-Мура. Правило плохого символа, правило хорошего суффикса

---

## 1. Идея алгоритма

**Алгоритм Бойера-Мура (Boyer-Moore)** — один из самых быстрых на практике алгоритмов поиска подстроки. В отличие от KMP и Z-функции, которые сканируют текст **слева направо**, Бойер-Мур сравнивает символы образца **справа налево**.

> **Главное преимущество:** При несовпадении алгоритм может сдвинуть образец сразу на несколько позиций вправо, пропуская значительные участки текста. В лучшем случае работает за $O(n/m)$, то есть **сублайнно** (не читает каждый символ текста). На практике часто быстрее KMP для длинных паттернов и больших алфавитов.

Алгоритм использует два правила для вычисления безопасного сдвига при несовпадении:
1.  **Правило плохого символа (Bad Character Rule)**
2.  **Правило хорошего суффикса (Good Suffix Rule)**

Берётся **максимум** из двух предложенных сдвигов.

---

## 2. Правило плохого символа (Bad Character Rule)

### Суть
При несовпадении символа текста $T[i]$ с символом образца $P[j]$ (где $j < m$), мы знаем, что $T[i] \neq P[j]$. Символ $T[i]$ называется **плохим символом**.

Мы хотим сдвинуть образец вправо так, чтобы этот плохой символ текста совпал с таким же символом в образце (если он там есть), расположенным как можно правее, но левее позиции $j$.

### Формализация
Пусть $\text{last}(c)$ — индекс **самого правого** вхождения символа $c$ в образец $P$ (или $-1$, если $c$ отсутствует в $P$).

При несовпадении в позиции $j$ образца с текстом:
$$\text{shift}_{bad} = j - \text{last}(T[i])$$

Если $\text{last}(T[i]) = -1$ (символа нет в образце), то $\text{shift}_{bad} = j + 1$ (сдвигаем образец полностью за плохой символ).

> **Важно:** Сдвиг должен быть положительным. Если $\text{last}(T[i]) > j$, то формула даст отрицательный сдвиг; в этом случае правило плохого символа предлагает сдвиг 0 (или 1), и решение принимает правило хорошего суффикса.

### Предобработка
Таблица $\text{last}[c]$ строится за $O(m + |\Sigma|)$:

```cpp
// last[c] = самый правый индекс символа c в pattern, или -1
std::vector<int> buildBadCharTable(const std::string& pattern, int alphabetSize) {
    std::vector<int> last(alphabetSize, -1);
    for (int i = 0; i < (int)pattern.size(); ++i) {
        last[(unsigned char)pattern[i]] = i;
    }
    return last;
}
```

## 3. Правило хорошего суффикса (Good Suffix Rule)

### Суть
При несовпадении в позиции $j$ мы знаем, что суффикс $P[j+1..m-1]$ **уже совпал** с соответствующим участком текста. Этот совпавший суффикс называется **хорошим суффиксом**.

Мы хотим сдвинуть образец вправо так, чтобы:
-   **Случай A:** Хороший суффикс совпал с другим вхождением того же суффикса в образце, причём перед этим вхождением стоит **другой** символ (не тот, что вызвал несовпадение).
-   **Случай B:** Если такого вхождения нет, ищем **наибольший префикс** образца, который совпадает с **суффиксом** хорошего суффикса.

### Формализация через таблицу good_suffix

Определим массив $\text{gs}[j]$ для каждой позиции $j$ ($0 \leq j < m$):
- $\text{gs}[j]$ = минимальный сдвиг, при котором хороший суффикс $P[j+1..m-1]$ корректно выравнивается с текстом.

Для эффективного вычисления используются два вспомогательных массива:
- $\text{suff}[i]$ — длина наибольшего суффикса $P[0..i]$, который также является суффиксом всего образца $P$.
- На основе $\text{suff}$ строится таблица $\text{gs}$.

### Построение таблицы хорошего суффикса (C++)

```cpp
// suff[i] = длина наибольшего общего суффикса P[0..i] и P[0..m-1]
std::vector<int> computeSuffixes(const std::string& p) {
    int m = p.size();
    std::vector<int> suff(m, 0);
    suff[m - 1] = m;
    
    int g = m - 1, f = 0; // границы текущего z-блока (аналогично Z-функции)
    
    for (int i = m - 2; i >= 0; --i) {
        if (i > g && suff[i + m - 1 - f] < i - g) {
            suff[i] = suff[i + m - 1 - f];
        } else {
            if (i < g) g = i;
            f = i;
            while (g >= 0 && p[g] == p[g + m - 1 - f]) g--;
            suff[i] = f - g;
        }
    }
    return suff;
}

// gs[j] = безопасный сдвиг при несовпадении в позиции j
std::vector<int> buildGoodSuffixTable(const std::string& p) {
    int m = p.size();
    auto suff = computeSuffixes(p);
    std::vector<int> gs(m, m); // По умолчанию: сдвиг на всю длину
    
    // Случай B: префикс образца = суффикс хорошего суффикса
    int j = 0;
    for (int i = m - 1; i >= 0; --i) {
        if (suff[i] == i + 1) { // P[0..i] является суффиксом P
            while (j < m - 1 - i) {
                if (gs[j] == m) gs[j] = m - 1 - i;
                j++;
            }
        }
    }
    
    // Случай A: точное вхождение хорошего суффикса с другим предшествующим символом
    for (int i = 0; i < m - 1; ++i) {
        gs[m - 1 - suff[i]] = m - 1 - i;
    }
    
    return gs;
}
```

## 4. Полный алгоритм Бойера-Мура (C++)

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

const int ALPHABET_SIZE = 256;

std::vector<int> boyerMooreSearch(const std::string& text, const std::string& pattern) {
    std::vector<int> occurrences;
    int n = text.size(), m = pattern.size();
    if (m > n || m == 0) return occurrences;

    auto last = buildBadCharTable(pattern, ALPHABET_SIZE);
    auto gs = buildGoodSuffixTable(pattern);

    int s = 0; // Текущий сдвиг
    while (s <= n - m) {
        int j = m - 1;

        // Сравнение справа налево
        while (j >= 0 && pattern[j] == text[s + j]) {
            j--;
        }

        if (j < 0) {
            // Полное совпадение!
            occurrences.push_back(s);
            s += gs[0]; // Сдвиг для поиска следующего вхождения
        } else {
            // Несовпадение в позиции j
            int badCharShift = j - last[(unsigned char)text[s + j]];
            int goodSuffShift = gs[j];
            
            // Берём максимум (безопасный сдвиг)
            s += std::max(1, std::max(badCharShift, goodSuffShift));
        }
    }

    return occurrences;
}

int main() {
    std::string text = "GCATCGCAGAGAGTATACAGTACG";
    std::string pattern = "GCAGAGAG";

    auto result = boyerMooreSearch(text, pattern);
    std::cout << "Вхождения: ";
    for (int pos : result) std::cout << pos << " ";
    std::cout << "\n";
    return 0;
}
```

## 5. Оценка сложности

| Случай | Время | Примечание |
| :--- | :--- | :--- |
| **Лучший** | $O(n / m)$ | Ни один символ паттерна не совпадает с текстом |
| **Средний** | $O(n / m)$ – $O(n)$ | Зависит от алфавита и структуры данных |
| **Худший (базовый BM)** | $O(n \cdot m)$ | Паттерн типа `aaa...a`, текст `aaa...a` |
| **Худший (BM + Galil rule)** | $O(n + m)$ | Модификация Галила устраняет квадратичность |
| **Предобработка** | $O(m + |\Sigma|)$ | Таблицы bad char + good suffix |
| **Память** | $O(m + |\Sigma|)$ | Две таблицы |

> **На экзамене важно отметить:** Базовый алгоритм Бойера-Мура имеет худший случай $O(nm)$. Для гарантии линейности используется **правило Галила** (Galil's rule), которое запоминает уже проверенные совпадения и не перепроверяет их после большого сдвига. Именно модификация BM + Galil даёт гарантированное $O(n + m)$.

## 6. Сравнение правил

| Характеристика | Bad Character | Good Suffix |
| :--- | :--- | :--- |
| **Информация** | Один символ текста | Весь совпавший суффикс |
| **Эффективность** | Лучше для больших алфавитов | Лучше для малых алфавитов и повторяющихся паттернов |
| **Простота реализации** | Простая | Сложная |
| **Сдвиг** | Может быть отрицательным (игнорируем) | Всегда положительный |
| **Необходимость** | Обязательна | Опциональна (но значительно ускоряет) |

На практике оба правила используются вместе, берётся $\max(\text{badCharShift}, \text{goodSuffShift})$.

## 7. Резюме для экзамена

1. **Бойер-Мур** сравнивает паттерн с текстом **справа налево**, что позволяет делать большие сдвиги.
2. **Правило плохого символа:** При несовпадении сдвигаем паттерн так, чтобы плохой символ текста совпал с самым правым таким же символом в паттерне. Таблица $\text{last}[c]$.
3. **Правило хорошего суффикса:** При несовпадении используем информацию о совпавшем суффиксе. Два случая: точное вхождение суффикса в другом месте паттерна (A) или совпадение префикса паттерна с суффиксом хорошего суффикса (B).
4. **Сдвиг:** $\max(\text{badCharShift}, \text{goodSuffShift})$.
5. **Сложность:** Лучший $O(n/m)$, средний $O(n)$, худший базовый $O(nm)$, с правилом Галила — $O(n+m)$.
6. **Практика:** Один из самых быстрых алгоритмов для длинных паттернов и больших алфавитов. Используется в `grep`, текстовых редакторах, биоинформатике.
